# THE MUSEUM OF POSSIBLE FUTURES
*An Experimental Spatial 3D Web Installation & Branching Civilization Simulator*

---

> "The future is not one destination. It is a collection of possibilities created by human decisions."

---

## 🏛️ Overview

**The Museum of Possible Futures** is a digital art installation and spatial 3D web experience exploring speculative futures of humanity. Moving away from conventional page layouts, the museum functions as a physical-digital chamber where visitors enter an atmospheric void, explore orbiting speculative artifacts, and actively influence civilizational trajectories through an interactive **Future Fork DAG Engine**.

---

## ✨ Flagship Systems & Highlights

1. **The Void & Cinematic Entrance**:
   - Near-black cosmic void with procedural star-dust particles.
   - Cinematic GSAP camera warp that sweeps past a fracturing quantum portal into the Central Atrium.
2. **The Central Atrium**:
   - Monumental architectural chamber with open front sightlines and perimeter colonnades.
   - Elliptical orbit carousel with 12 speculative future artifacts.
   - 3D floating holographic labels and reactive pedestal floor rings.
3. **Interactive Flagship Artifacts**:
   - **Synthetic Memory (`EXHIBIT 001`)**: Translucent crystalline prism containing internal synaptic firing neuron particles.
   - **Post-Work Society (`EXHIBIT 003`)**: Multi-axis kinetic golden gear matrix transitioning into glowing computational energy.
   - **The Last Forest (`EXHIBIT 002`)**: Cryogenic quantum containment rings preserving bioluminescent flora.
   - **Artificial Life (`EXHIBIT 005`)**: Deforming cellular organic mesh.
   - **Lunar Civilization (`EXHIBIT 006`)**: Orbital moon settlement with active day/night terminator lines.
   - **Unknown Monolith (`EXHIBIT 000`)**: Redacted non-reflective geometry exhibiting gravitational lensing and anomaly states.
4. **Future Fork DAG Engine (Branching Civilization Simulator)**:
   - First-class Directed Acyclic Graph (DAG) state tree.
   - Decisions dynamically reconfigure global world state (lighting temperature, volumetric fog density, particle colors, harmonic audio base, and available exhibits).
5. **The Year Machine**:
   - Precision temporal continuum scrubber (2026 $\rightarrow$ 2150) with decade snapping.
6. **Impossible Archive**:
   - Speculative specimen matrix with category filtering (Nature, AI, Space, Culture, Unknown) and real-time search.
7. **Future Laboratory**:
   - Interactive speculative technology simulator with live telemetry readouts for cognitive latency, planetary entropy, and longevity.
8. **Web Audio API Generative Synthesizer**:
   - Procedural ambient sub-bass drone and spatial harmonic chime signatures (muted by default).
9. **Precision Custom Cursor**:
   - Hardware-accelerated with 60fps RAF lerp trailing and 7 reactive interaction states (`normal`, `interactive`, `inspect`, `enter`, `drag`, `zoom`, `anomaly`).

## 🛠️ Technology Stack

- **Core**: React 19 + TypeScript + Vite 8
- **3D & WebGL**: Three.js + `@react-three/fiber` + `@react-three/drei` + `@react-three/postprocessing`
- **Motion & Cinematic Choreography**: GSAP (Core + CustomEase)
- **State Machine**: Zustand (`useMuseumStore`)
- **Sound Engine**: Web Audio API (Procedural Synthesizer)
- **Styling**: Vanilla CSS Design Token Architecture (Zero generic utility bloat)
- **Icons**: Lucide React

## 🚀 Getting Started

### Installation
```bash
# Clone the repository
git clone https://github.com/AdwaitPr/Socretes_Vengeance-.git
cd Socretes_Vengeance-

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```

- `1`: Jump to Central Atrium
- `2`: Jump to Future Fork
- `3`: Open Specimen Archive
- `4`: Open Year Machine
- `5`: Enter Future Laboratory
- `Escape`: Return to Central Atrium
- `M`: Toggle ambient procedural audio
- `←` / `→`: Scrub Year Machine by decade
